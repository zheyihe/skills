# 原研哉调研 01｜著作与系统思考

调研日期：2026-04-14
聚焦主题：`空 / 白 / ex-formation / haptic / 设计是条件而非物`

## 一手来源清单

### 1. HARA DESIGN INSTITUTE 官方简介
- 类型：一手
- 可信度：高
- 来源：https://hara.ndc.co.jp/en/about/
- 要点：
  - 官方自述把原研哉定位为同时设计“objects and experiences”的设计师。
  - 官方履历把 `RE-DESIGN`、`HAPTIC`、`TOKYO FIBER -- SENSEWARE` 连成一条线，说明他不是从风格入手，而是在持续扩展“感知如何被唤醒”的设计议题。
  - 官方简介直接写明：`RE-DESIGN` 证明惊人的设计资源隐藏在“the very ordinary and casual”之中。

### 2. 《DESIGN OF DESIGN / DESIGNING DESIGN》官方书页
- 类型：一手
- 可信度：高
- 来源：https://hara.ndc.co.jp/en/books/design-no-design/
- 要点：
  - 官方说明这本书不是作品集，而是设计师以作者身份对设计的俯瞰性论述。
  - 这意味着原研哉的核心输出不只是项目结果，而是“如何重新理解设计”的框架化思考。

### 3. 《WHITE》官方书页
- 类型：一手
- 可信度：高
- 来源：https://hara.ndc.co.jp/en/books/shiro/
- 要点：
  - 官方定义非常明确：`white` 不是颜色，而是日本文化中的一种“sensory resource”。
  - 这本书回溯谷崎润一郎、九鬼周造、冈仓天心、新渡户稻造等文本，说明原研哉不是把“白”当成视觉偏好，而是当作文化与感知结构。

### 4. 《WHITE》英文摘录
- 类型：一手
- 可信度：高
- 来源：https://newsroom.porsche.com/dam/jcr%3A32ec856d-c046-4c3e-b0ee-64f135d6dc3a/EN_CPM_385_Kenya%20Hara%20Buchauszug.pdf
- 要点：
  - 原研哉明确说：他的职业是 communication，工作重点是展示 `circumstances` 或 `conditions`，而不是制造“things”。
  - 他把 `emptiness` 与 `white` 连起来理解：先从“空”入手，最终逼出对“白”的追问。
  - 他把有效沟通理解为“listen more than push opinions”，并用 `empty vessel` 解释符号为何应留下想象的容量。

### 5. 《Ex-formation》官方书页
- 类型：一手
- 可信度：高
- 来源：https://hara.ndc.co.jp/en/books/ex-formation/
- 要点：
  - `Ex-formation` 被官方定义为：不是 `making things known`，而是 `making things unknown`。
  - 核心不是灌输知识，而是让人意识到自己其实并不知道多少。
  - 这是原研哉最像“自创术语”的概念，也是他对传播设计的结构性修正。

### 6. 《HAPTIC—Awakening the Senses》官方书页
- 类型：一手
- 可信度：高
- 来源：https://hara.ndc.co.jp/en/books/haptic/
- 要点：
  - 官方定义：把重点从颜色、形状、纹理、均衡这些外在因素，移到“how we feel”。
  - 这证明原研哉对“空”和“白”的讨论，并不是抽象玄学，而是始终落在身体感知的激活上。

## 反复出现的核心论点

### 1. 设计不是制造物，而是设置条件
- 证据：
  - `WHITE` 摘录：设计师的专业是 communication，表达的是 `circumstances` / `conditions`。
  - 官方简介：原研哉强调 objects and experiences 双重设计。
  - `JAPAN HOUSE` 等项目里，他反复把空间、符号、叙事组织为一个容器，而不是单一物件。
- 判断：
  - 这不是一次性表述，而是他如何定义职业本体。

### 2. “白”不是颜色，而是感知被整理后的纯净状态
- 证据：
  - `WHITE` 官方书页直接定义。
  - `WHITE` 摘录把 white 与 cultural sensitivity 绑定。
  - 外部高质量综述也反复指出 Hara 的 white 是 design concept，而非审美偏好。
- 判断：
  - `白` 是原研哉体系的入口概念，不是表面风格。

### 3. “空”不是空无，而是允许意义自由进入的大容器
- 证据：
  - `WHITE` 摘录：cross / 日之丸 red disk / teahouse 都被他当作 `empty vessel`。
  - `JAPAN HOUSE` 官方项目页把“一”定义为能够容纳自由见立的“大容量图像器”。
  - 2011 访谈中他把 emptiness 说成 `blank canvas that calls forth different images`。
- 判断：
  - “空”在原研哉这里是高容量、可承载、多义性的结构。

### 4. 传播设计应该先制造“未知感”，而不是急着解释
- 证据：
  - `Ex-formation` 官方书页直接定义。
  - 多个二手高质量解读都把它总结为：发现已知之内尚未被提问的问题。
- 判断：
  - 这说明他反对过饱和的信息填塞，主张把接收者重新放回主动状态。

### 5. 感官是设计的真正起点
- 证据：
  - `HAPTIC` 官方书页。
  - 官方简介中的 `HAPTIC`、`TOKYO FIBER -- SENSEWARE`。
- 判断：
  - 原研哉讨论“空”和“白”时，底层逻辑始终是感官被唤醒，而不是形式被简化。

### 6. 巨大的设计资源潜伏在日常与普通之中
- 证据：
  - 官方简介对 `RE-DESIGN` 的总结。
  - MUJI 长期项目总是用洗衣、扫除、住、茶室、地平线这些日常母题，而不是奢侈新品。
- 判断：
  - 这条信念后来成为他连接 MUJI、产业、文化资源的基础。

## 自创术语与高识别度概念

### Ex-formation
- 类型：一手
- 可信度：高
- 来源：https://hara.ndc.co.jp/en/books/ex-formation/
- 说明：
  - 这是最明确、最可操作的原研哉自创概念。
  - 它与“空”的关系是：不是把信息填满，而是把已知拆开，让接收者重新参与。

### Senseware
- 类型：一手 + 二手交叉
- 可信度：中高
- 来源：
  - 一手背景：https://hara.ndc.co.jp/en/about/
  - 二手综述：https://www.dmh.org.il/en/articles/designing-design-kenya-hara/
- 说明：
  - 官方简介已把 `TOKYO FIBER -- SENSEWARE` 列为关键展览。
  - 二手综述进一步把它解释为“刺激感官的媒介”。
  - 可安全视为他稳定使用的一组概念群。

## 初步结论

### 候选真信念（通过 3 次以上复现）
1. 设计的核心是组织感知条件，不是堆叠造型。
2. “白”与“空”是让意义进入的高敏感状态，而不是空白画面。
3. 传播最强的时刻，不是说明完毕，而是让人重新意识到自己尚未知道。
4. 日常事物不是平庸素材，而是最稳定的设计资源。
5. 感官激活比视觉装饰更接近设计本体。

### 需要在后续维度继续验证的点
- `emptiness` 到底是独立心智模型，还是 `white / ex-formation / senseware` 的总框架。
- 他对“日本文化资源”的强调，是开放性的资源观，还是存在文化本质化风险。
